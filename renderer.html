ALTTPR PO LAUNCHER

This guide takes about two minutes. It goes through each thing the launcher works with, in the order you'll use them. Every step can be skipped and finished later from Settings → Setup guide.

You already have a setup from an earlier version. This is a quick check that everything is still where it was; anything that has moved is marked.

You'll want to have installed: BizHawk (the emulator) and SNI (it comes with Archipelago and connects the tracker to the game). Optional: LiveSplit, MSU-1 music packs, and Archipelago if you play multiworld.

BizHawk is the emulator the launcher starts. Point it at EmuHawk.exe, the file that opens BizHawk. It lives wherever you unzipped BizHawk, in a folder named like BizHawk-2.x-win-x64.

Not set
One setting inside BizHawk matters: Config → Customize → tick Save Window Position. The launcher never moves BizHawk's main window itself; with that ticked, BizHawk goes back where you left it.

Lua connector. Connector.lua is a small script that lets the tracker and Archipelago follow your game. It ships with SNI.

Not found

SNI is a small program that connects the tracker (and Archipelago) to the running game. It is installed with Archipelago and normally sits at C:\ProgramData\Archipelago\SNI\sni.exe.

Not set
SNI opens a console window while it runs. SNI has its own option to hide that window; the launcher doesn't control it.

Optional. If you use LiveSplit, point the launcher at LiveSplit.exe. It will open with the game and be put back in place with your saved layout.

Not set

Don't use a timer? Skip this step.

The seeds folder is where your downloaded seeds arrive. For most people that's Downloads. The launcher watches it and picks up the newest .sfc or .aplttp automatically each time it starts.

Not set

You can also drop a seed file straight onto the main window at any time.

Optional. MSU-1 packs replace the game's music. Pick the folder that holds your packs: each pack is its own folder with a .msu file inside, and the launcher looks up to three folders deep, so a folder of folders is fine.

Not set

No music packs? Skip this step — you'll play with the original soundtrack, and can add packs later.

Archipelago is installed. For multiworld seeds (.aplttp) the launcher starts the emulator itself. If Archipelago's own start ROM setting is also on, the emulator opens twice.

This sets snes_rom_start and rom_start to false in Archipelago's host.yaml. A backup of the original is kept next to it, and unticking puts the old values back.

The tracker shows your items and dungeons and follows the game through SNI. It needs a preset once:

  1. Click Open tracker settings below.
  2. In the window that opens, choose your settings: game mode, goal, dungeon items, and so on.
  3. Press LAUNCH TRACKER at the bottom of that window. That saves the preset.
No preset yet

Play a different mode later? Open tracker settings again and press LAUNCH TRACKER to save a new preset.

Nothing to set here; this is just so you know how layouts work.

  1. Launch a seed once. BizHawk, the Lua console, the tracker and the timer open.
  2. Drag each window where you want it.
  3. Click Save layout on the main screen. From then on, every launch puts the windows back there.

There are two layouts: one for normal seeds (.sfc) and one for Archipelago seeds (.aplttp). Save each once.
